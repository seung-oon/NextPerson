# 다음 분이요! (NextPerson!)

은행 창구 업무 시뮬레이션 게임입니다. 플레이어는 신입 행원이 되어 창구에 찾아오는 손님을
한 명씩 응대하고, 모니터에 뜬 고객 정보를 보고 요청을 **처리할지 거절할지** 판단합니다.
구조는 *Papers, Please*(Lucas Pope, 2013)에서 가져왔습니다. 여권 심사 자리에 은행 창구를,
입국 규정 자리에 금융 규제를 넣었습니다.

XR 프로그래밍 수업 텀프로젝트로 만들었습니다. 1인칭 창구 환경을 Unity 6(URP)로 구성했습니다.

## 플레이 흐름

1. 손님이 출입문에서 걸어 들어와 창구 앞 트리거 영역(`CounterZone`)에 도착합니다.
2. **본인확인**: 연락처 확인 같은 질문이 비주얼노벨식 3지선다로 나옵니다.
   틀린 선택지를 고르면 그 자리에서 응대 실패로 처리됩니다.
3. **고객 정보 검토**: 모니터에 요청 업무·금액과 함께 신용점수·DSR·총부채,
   FDS 위험 등급, 계좌 제한(압류·가압류·질권·사고신고·한도제한), 연체 이력,
   고객확인(CDD/EDD) 상태가 표시됩니다.
4. **처리완료 / 거절** 중 하나를 누르면 정답 여부와 근거 규정이 결과 패널에 나옵니다.
5. 손님 한 명당 제한시간은 25초입니다. 시간이 지나면 손님이 화를 내며(Angry 애니메이션) 떠나고
   불만이 1건 접수됩니다.

정답은 +10점, 오답이나 시간 초과는 −5점에 불만 +1입니다. 점수가 쌓이면 직급이
사원 → 주임 → 대리 → 과장 → 차장 → 부장 → 지점장 순으로 오릅니다.
불만이 5건 쌓이면 **권고사직**으로 게임이 끝납니다.

## 고객 케이스

`Assets/Scripts/CustomerData.cs`에 고객 50명을 직접 작성해 두었습니다.
업무 유형은 26가지(출금·이체·대출상담·외화환전·해외송금·상속처리·대리인거래·펀드가입 등)이고,
50명 중 24명은 정상 처리 대상, 나머지는 실제 창구에서 거절 사유가 되는 규정에 걸리도록 설계했습니다.

| 거절 사유 예시 | 근거 |
|---|---|
| DSR 67.3%로 규제 한도(40%) 초과 | 차주별 DSR 규제 |
| 최근 20영업일 안에 타행 계좌 2건 개설 | 대포통장 방지(단기간 다수 계좌 개설 제한) |
| 고객확인 이행 거부 | 특정금융정보법 제5조 |
| 1만 달러 초과 환전인데 자금 원천 미확인 | 강화된 고객확인(EDD) |
| 안정형 고령 투자자에게 고위험 펀드 | 금융소비자보호법 적합성·적정성 원칙 |
| 질권설정·가압류 계좌 출금 | 잔액이 있어도 처리 불가 |
| 위임장·인감증명서 없는 대리 출금 | 대리인 거래 요건 |

같은 "출금"이라도 잔액 부족, 압류, 보이스피싱 의심 등 서로 다른 이유로 막히게 해서
업무 유형만 보고 답을 외울 수 없도록 했습니다.

> 기획 단계에서는 생성형 AI(Gemini 2.5 Flash Lite)로 고객 케이스와 안내 문구를 실시간으로
> 만들 계획이었습니다. 현재 구현은 규정 근거를 직접 검수한 고정 케이스 큐를 씁니다.

## 코드 구조

| 스크립트 | 역할 |
|---|---|
| `BankGameManager` | 게임 상태 머신(대기 → 창구 도착 → 처리 중 → 종료), 손님 생성·순서, 제한시간, 점수·직급·불만 집계 |
| `BankCustomer` | 손님 이동(출입문 → 창구 → 출구)과 Walk/Angry 애니메이션. 루트 모션을 끄고 Transform으로 직접 이동 |
| `CounterZone` | 창구 앞 트리거. 손님 Collider가 들어오면 도착 이벤트 발생 |
| `CustomerData` | 고객 데이터 스키마와 50명 샘플 큐, 이름 기반 성별 추정(프리팹 선택용) |
| `MonitorController` | 모니터 UI(본인확인 → 정보 → 처리/거절 → 결과) 패널 전환 |
| `ScoreHUD` | 직급·점수·불만·대기 인원·타이머 HUD, 일과 종료/게임오버 화면 |

## 실행 환경

- Unity **6000.3.9f1**, Universal Render Pipeline
- 패키지: Input System, TextMesh Pro(uGUI), AI Navigation 등(`Packages/manifest.json`)

## 에셋 준비

라이선스상 재배포할 수 없는 에셋은 저장소에서 뺐습니다. 클론 후 아래 파일을 직접 넣어야
씬이 원래대로 보입니다.

1. **손님 캐릭터**: [Mixamo](https://www.mixamo.com/)에서 캐릭터 3종과 애니메이션
   (`T-Pose`, `Walking`, `Angry Gesture`)을 FBX로 받아 `Assets/Character/Ch01`, `Ch22`, `Ch33`에 넣습니다.
   `Assets/Character/Prefabs`와 `Animators`의 프리팹·컨트롤러는 저장소에 있으니 모델 참조만 다시 연결하면 됩니다.
2. **한글 폰트**: 한글 글리프가 있는 TTF(원본은 맑은 고딕)를 `Assets/Fonts`에 넣고
   `Window > TextMesh Pro > Font Asset Creator`로 SDF 에셋을 만들어 UI 텍스트에 지정합니다.
   맑은 고딕은 Windows 번들 폰트라 재배포가 안 되므로, 공개 빌드에는
   [Noto Sans KR](https://fonts.google.com/noto/specimen/Noto+Sans+KR) 같은 OFL 폰트를 권합니다.

스카이박스 HDRI(`docklands_01_4k.hdr`)는 [Poly Haven](https://polyhaven.com/a/docklands_01)의 CC0 에셋입니다.
